# abacuslite 1.1.0 release

## Final status

Published to [PyPI](https://pypi.org/project/abacuslite/1.1.0/) and
[GitHub Releases](https://github.com/QuantumMisaka/abacuslite/releases/tag/v1.1.0)
on 2026-10-18 (UTC+08:00). The exact tag CI artifacts passed registry digest
checks and fresh indexed-install acceptance. The source tag remains at
`94a26e4c7f31ed817eac36c871ff74a7b7abe418`; later documentation commits record
publication evidence without changing or rebuilding the released files.

## Verification and recovery

Existing candidate package evidence is four 148-pass/19-opt-in-skip runs plus
10 installed consumer contracts. Final versioned artifact checks must record
their own identities. Publication takes the successful CI run's artifacts,
without rebuilding between verification and upload. Invalid source runs,
prerelease/version mismatches and incomplete distributions must fail before
the upload job. Missing PyPI account binding leaves publication pending;
it does not permit a token to be sent through chat or an unverified upload.

Retain worktrees, source commits and build/test logs. Do not overwrite an
existing PyPI version or move an existing release tag. If publication partially
succeeds, inspect the registry and exact file digests before deciding recovery.

## Publication and indexed-install acceptance

After that confirmation, the failed upload job was retried using the already
verified artifacts:

```bash
gh run rerun 39047128384 --failed --repo QuantumMisaka/abacuslite
```

[Attempt 2](https://github.com/QuantumMisaka/abacuslite/actions/runs/39047128384/attempts/2)
succeeded. PyPI records the wheel upload at `2026-10-17T17:58:00.583873Z`
and the sdist upload at `2026-10-17T17:58:02.010801Z` (2026-10-18 locally).
The version JSON contains exactly the two expected files, neither yanked.
Registry SHA256 values and independent downloads both match the table above;
no artifact was rebuilt for publication.

A fresh Python 3.12.3 environment installed `abacuslite==1.1.0` with
`--index-url https://pypi.org/simple --no-cache-dir`. The pip install report
identifies the same wheel digest from `files.pythonhosted.org`. Installed
dependencies include ASE 3.29.0, NumPy 2.5.4 and seekpath 2.2.2.
`pip check` reports no broken requirements. Imports of `Abacus`,
`AbacusProfile`, `AbacusSocketIO`, both output readers, general I/O and K-point
helpers passed; the package resolves inside the environment's site-packages.
An engine-free INPUT write/read round trip also passed.

The tests extracted from the published sdist ran against that indexed wheel
using `python -I -m pytest -q`: **148 passed, 19 skipped**, with 106 existing
ASE/NumPy warnings. The skips explicitly require engine/consumer opt-in;
this publication check does not replace the tag CI's consumer evidence or
the earlier source-bound real-engine acceptance.
