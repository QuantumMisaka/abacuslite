# abacuslite 1.2.0 release

## Status

Published on [PyPI](https://pypi.org/project/abacuslite/1.2.0/) on
2026-10-19 (UTC+08:00) from the immutable annotated tag `v1.2.0` (tag object
`d7ce83f`, commit `7e6761d`, the merge commit of PR #6). The tag push run of
Package tests passed, and the manual `publish.yml` run uploaded that run's
`distributions-3.12` artifacts without rebuilding. The source baseline is merged
`main` `87f0960` (PR #5).

The branch was first prepared as a patch candidate (`1.1.1`) and re-versioned to
`1.2.0` after review: `5bbfbaf` adds a capability that neither code nor docs
contained in `v1.1.0`, so a minor release is the correct semver call. The
earlier candidate commits remain in the branch history; the final tree is
`1.2.0`.

## Scope

### Added (`5bbfbaf`, PR #1)

`AbacusProfile` defaults `pseudo_dir` and `orbital_dir` to `ABACUS_PP_PATH` and
`ABACUS_ORB_PATH`. They are the package's only asset-directory environment
defaults and were not present in `v1.1.0`.

An independent runtime review found that the first implementation
(`pseudo_dir or os.environ[...]`) also replaced an explicit empty string with the
environment value, which contradicts the stated precedence. The candidate now
falls back only when the argument is `None`, so explicit values - including an
empty string - are preserved. Two regressions cover the `None` fallback and the
preserved empty string.

### Fixed (`dee3fc8`, PR #3)

- Write ASE atom masses, including isotope masses, to STRU per species, and
  reject different masses within one species before writing;
- resolve the fixed-density charge directory from the source calculation's
  output suffix while retaining an explicit `read_file_dir`;
- restart from the STRU file selected by INPUT and read KPT only when needed.

### CI and documentation

The remaining commits since `v1.1.0` are package CI (`4772dd5`, `d6a9c4b`,
`6de3b83`), documentation and maintainer records (`8ed1ba2`, `7f17ec4`,
`4215b71`, `e365b8d`, `531f7c8`, `a9ae811`, `942586a`, `87f0960`) and this
release preparation.

PR #5 (`87f0960`) repaired consumer CI references: the scheduled ATST lane now
follows ATST `main`, and the pinned consumer revision moved from the
non-mainline `07aba23` to ATST `49c8626` (2.3.0). ATST `main` advanced one
documentation-only commit (`fa1ba07`) afterwards; the pin intentionally stays at
the reviewed 2.3.0 commit while the scheduled lane tracks ATST `main`.

No reader-shape or public-import change is included: `abacuslite/io/legacyio.py`
and `abacuslite/io/latestio.py` are unchanged since `v1.1.0`. ATST declares
`abacuslite>=1.1.0,<2`, so `1.2.0` satisfies it.
