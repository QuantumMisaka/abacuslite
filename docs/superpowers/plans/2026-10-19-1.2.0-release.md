# abacuslite 1.1.1 release

## Status

Local release candidate on branch `release/1.1.1`, based on merged `main`
`87f0960` (squash merge of PR #5, 2026-10-18T17:16Z). The candidate is versioned
`1.1.1` and is **not** tagged, pushed or published. Tag creation, publication
and any remote action still require explicit maintainer authorization.

`main` and the PR head `6409df6` have the same runtime tree; only documentation
and CI pins differ. That commit is the source of the candidate for this release,
not the published `1.1.0` wheel.

## Scope

The release republishes `main` after `v1.1.0` with two runtime commits:

- `5bbfbaf` (PR #1): `AbacusProfile` defaults `pseudo_dir` and `orbital_dir` to
  `ABACUS_PP_PATH` and `ABACUS_ORB_PATH` when the arguments are omitted;
  explicit arguments still take precedence.
- `dee3fc8` (PR #3): three calculator and restart corrections:
  - write ASE atom masses, including isotope masses, to STRU per species, and
    reject different masses within one species before writing;
  - resolve the fixed-density charge directory from the source calculation's
    output suffix while retaining an explicit `read_file_dir`;
  - restart from the STRU file selected by INPUT and read KPT only when needed.

The remaining commits since `v1.1.0` are CI (`4772dd5`, `d6a9c4b`, `6de3b83`),
documentation and maintainer records (`8ed1ba2`, `7f17ec4`, `4215b71`,
`e365b8d`, `531f7c8`, `a9ae811`, `942586a`, `87f0960`), plus this release
preparation.

PR #5 (`87f0960`) repaired consumer CI references: the scheduled ATST lane now
follows ATST `main`, and the pinned consumer revision moved from the
non-mainline `07aba23` to ATST `49c8626` (2.3.0). ATST `main` advanced one
documentation-only commit (`fa1ba07`) afterwards; the pin intentionally stays at
the reviewed 2.3.0 commit while the scheduled lane tracks ATST `main`.

No public import, unit, atom-order or reader-shape change is included.
`abacuslite/io/legacyio.py` and `abacuslite/io/latestio.py` have no diff since
`v1.1.0`, so the ATST/Forge read contract is unchanged.

Semver note: `5bbfbaf` adds user-visible default resolution, which is additive
rather than a pure fix. The maintainer selected a patch release (`1.1.1`) for
this batch; ATST declares `abacuslite>=1.1.0,<2`, so `1.1.1` satisfies it.

## Remaining gates

1. Maintainer authorization to create tag `v1.1.1` from the release commit on
   `main`.
2. Tag push run of Package tests; publication consumes that run's
   `distributions-3.12` artifact without rebuilding.
3. Publish through `publish.yml` from `main` with the tag and tag-run ID; only
   the upload job receives OIDC permission.
4. After upload, compare PyPI SHA256 digests, verify
   `pip install abacuslite==1.1.1` and `pip check` in a fresh environment, then
   record publication status here, in `CHANGELOG.md` and in the README.
5. Consumer bookkeeping: Forge rebinds its exact extra to `1.1.1`; ATST records
   its CI pin accounting separately.

## Recovery

Never move the tag or replace a published artifact. If an upload partially
succeeds, inspect the registry before retrying and do not silently skip
conflicting files. A failed tag run is fixed on `main` and re-released with a
new reviewed tag; it is not retried by editing the release commit.
