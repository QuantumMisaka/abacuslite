# abacuslite 1.2.1 release

Date: 2026-10-20 (UTC+08:00). Scope: entropy-aware `free_energy` fix.

## Source and behavior

The release keeps `energy = E_KohnSham` and reports
`free_energy = E_KohnSham - E_entropy(-TS)`. This restores the
force-consistent energy convention required by FCP v2 and by ATST
constant-potential calculations on smeared systems. The legacy and latest
readers are covered by real entropy-bearing fixtures.

## Validation

- `PYTHONPATH=src pytest tests/unit -q`: 168 passed, 2 skipped
  (`requires --run-engine`).
- Built wheel metadata reports `1.2.1`; the installed wheel returns
  `energy=-1940.5509086572` and `free_energy=-1940.3851061128998` on the
  `multiframe_md_legacy` fixture.
- The fix was exercised in the ATST LTS FCP v2 parity run (SAI job `1864305`)
  and the beta6/beta9/latest-develop CP smoke runs (jobs `1864431`, `1864468`,
  `1864773`).
- Wheel and sdist are built locally, checked with strict Twine, and tested by
  the Package tests workflow before publication.
