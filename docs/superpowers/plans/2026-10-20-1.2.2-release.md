## Behavior and verification

Implementation `e8e9b65` defines the public API and deprecation contract and
repairs file-backed noncollinear magnetic-result projection without changing
ASE's global registry. Existing energy conventions, bands and collinear
behavior are preserved. Maintenance options remain proposals.

The implementation and paired harness were independently reviewed; two
findings (nonzero socket-client exit handling and unsupported KPT writer
documentation) were fixed and rechecked. The
[local evidence record](2026-10-20-public-api-and-maintenance.md#evidence)
contains the regression failures, installed-package checks and dual-engine
results. Those used version 1.2.2.dev0 and retained engine binaries.

The stable candidate retains the same runtime implementation. Its hosted
release gates must cover the stable artifact, both installed-package and
consumer lanes, and cold-built develop/LTS engines through the new harness.
Only the harness reference changes: develop stays at `1bf602a` (beta11),
LTS at `725bf475` (3.10.1), and curated assets remain unchanged.

Ruling: publish the test-only branch before binding CI to its commit. This
does not merge the open upstream PR or publish a separate harness package.
Retain the published 1.2.1 README installation instructions until 1.2.2
publication is verified, then update the current-release pointers.
